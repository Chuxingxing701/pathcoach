# Slide data — source, license, reproduction

## Source

All whole-slide images are **TCGA** (The Cancer Genome Atlas) diagnostic/tissue
slides fetched from the NCI **Genomic Data Commons (GDC)** under open access
(`access = open`, `data_format = SVS`, ≤ 150 MB per file).

- Lung slides (24): TCGA-LUAD and TCGA-LUSC **frozen Tissue Slides** — normal
  lung has no FFPE slides in TCGA (see `docs/decisions.md` ADR-006).
- Other-site practice slides (4): TCGA-ESCA, TCGA-PAAD, TCGA-CESC, TCGA-HNSC
  **Diagnostic Slides** (FFPE).
- Trial slide: TCGA-BRCA (outside the study set, ADR-005).

Per-slide provenance (project, GDC file UUID, file name, case and sample IDs)
is published in `answers/<id>.json` and is fetched only **after** the user
submits a conclusion, so it cannot leak the label beforehand (ADR-004).

## Terms and attribution

TCGA data are available under the
[TCGA Data Use Policy](https://www.cancer.gov/ccg/research/genome-sequencing/tcga/history/ethics-policies)
and the [GDC Data Use Policies](https://gdc.cancer.gov/access-data/data-access-processes-and-tools/data-use-policies).
When using or citing this dataset, please credit:

> The results shown here are in part based upon data generated by the
> [TCGA Research Network](https://www.cancer.gov/tcga).

## Pipeline (reproduction)

All scripts live in `pipeline/` and need `pipeline/requirements.txt`
(libvips + openslide via conda-forge work on Windows/macOS/Linux):

```bash
python pipeline/select_slides.py     # GDC API -> pipeline/work/selection.json
python pipeline/download_slides.py   # -> pipeline/work/svs/<id>.svs (md5-checked)
python pipeline/tile_all.py          # -> pipeline/work/tiles-N/v1/<id>.dzi
python pipeline/qc_thumbs.py         # -> pipeline/work/qc/<id>.jpg
python pipeline/make_cases.py        # -> public/data/{cases,answers,manifest}
```

`pipeline/work/` is gitignored: raw slides, tiles and the private selection
metadata (which contains diagnoses) never enter the repository.
