## 2. 逐项说明

### 盲法边界（R3 重点）

- 病例库卡片只显示 `siteLabel`（如「肺」）、制片方式、ID —— 无诊断标签。状态「判对/判错」只对自己的历史结果显示，不构成新信息泄漏（是自己测出来的）。
- `answers/*.json` 仍然只在**用户提交结论之后**拉取（`loadAnswer` 仅在 `conclude`/`isRevealed` 路径调用）；揭晓前网络面板无 answers 请求。
- `validate:data` 泄漏检查全绿：case 文件不含标签词；模板内容（含「正常肺泡」「腺癌」等教学词）不在检查范围内、也不应检查——模板本来就要教形态学，不含具体某张切片的标签。

### 第 0 步门槛（R3 重点）

- 看片前必须完成：新手/熟练档填写模板里的回忆项（肺=正常结构构成+常见癌类型；other=对应部位版本，新手档有可点选项 chips），专家档自由文本写预期结构/鉴别。
- 完成即 `unlocked:true` 持久化 —— 之后切档不回锁；`step0Answers` 留在 session 里，揭晓后可对照自己看片前的预期。
- 可绕性声明：门槛校验的是「文本非空」，不校验内容质量——乱打几个字也能过。这是刻意为之（n=1 诚实性边界，同 ADR-004）；请审这个取舍是否可接受。

### 三档渲染语义

- `levels` 数组控制每步**条目**显隐；步骤标题永远显示（工作流骨架人人可见）。新手=hint+出处+全部条目；熟练=条目无 hint；专家=只剩 site 回忆与结论（条目不渲染）——「裸读+交结论」模式。

### 模板扩展性（R3 重点）

- 模板 = 纯数据 JSON（steps[]×items[]，`levels`/`targetMag`/`hint`/`sources`/`options` 字段），新增部位 = 写一个 JSON + case 指 `templateId`，零代码。
- schema 已更新：item 增加 `options`（第 0 步选项 chips）；规则「有 hint 必须有 ≥1 出处」继续有效。
- `other-v1` 证明了跨器官复用可行，但「六步 kind 枚举」是固定的（site/tissue/stain/pre-assessment/features/conclusion）——够 MVP，以后要加步型得改 schema+CasePage 分支。

## 3. 设计取舍与理由

- **标注存图像像素坐标**：随缩放/旋转投影到屏幕，不随窗口几何漂移；点/矩形/多边形覆盖「标记灶 / 框区域 / 描边界」三种意图。
- **非绘制时覆盖层 pointer-events 穿透**：标注工具平时完全不干扰 OSD 平移缩放；绘制时禁 OSD 鼠标导航。
- **条目作答 = 三值（有/无/不确定）+ 备注**：比二元更能暴露「拿不准」；点空值即删除该条记录。
- **揭晓即锁**：`revealedAt` 一写，条目/第 0 步/结论控件全部禁用——练前测的一次性语义延续到练习（防止先看答案再改答案）。
- **会话可重进**：练习不是考试，刷新/离开恢复现场；库卡片状态实时反映 session。
- **升档只建议不强制**：≥5/6 阈值+可忽略，避免频繁打扰；忽略以「窗口最新 session 的 updatedAt」为锚，窗口滑动后重新出现。
