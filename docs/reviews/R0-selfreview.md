# R0 自审意见（Devin，对 R0.md + decisions.md）

> 自审不能代替独立审核：这是我按审核清单逐条对照代码后找出的问题，建议连同本文件一起交给高级模型。

## Blocker

**B1 · 病例元数据里的 `source` 会泄漏标签（推翻 ADR-004 的结论）**
`cases/<id>.json` 的 `source.project`（`TCGA-LUAD` ⇒ 腺癌、`TCGA-LUSC` ⇒ 鳞癌）、`source.sampleType`（`Solid Tissue Normal` ⇒ 正常）、`source.fileName` / `submitterId`（条码 `-11A` ⇒ 正常、`-01A` ⇒ 肿瘤）都写在提交前就会加载的公开文件里，打开开发者工具或网络面板就能看到。ADR-004 说「标签不放进病例元数据」，但这几个字段等于把标签放进去了。练前 / 练后测同样受影响。
修复：`source` 整块挪到 `answers/<id>.json`（揭晓后展示出处）；病例 ID、DZI 文件名、瓦片路径一律用无含义的编号（`lung-07`），不能带 TCGA 条码或项目名；`validate-data` 加一条检查：case 文件里不得出现 `TCGA-LUAD|LUSC|Normal|-11[A-Z]|-01[A-Z]` 这类字符串。

## Major

**M1 · 审核包不能独立阅读**：R0.md 引用的开发计划和 v2.0 规格（「偏离 v2.0 §7」）只在我的私有记忆里，外部审核模型看不到。修复：把规格和计划放进仓库 `docs/spec-v2.md`、`docs/plan.md`。
**M2 · 中文字体问题没写进 R0**：测试截图中文渲染成方块，R0「已知问题」漏掉了。CSS 字体栈没有 Linux / 安卓常见的中文字体（`Noto Sans CJK SC`、`Source Han Sans SC`）。修复：补字体栈，换一台干净浏览器重新截图验证，R0 如实记录。
**M3 · ADR-006 提议（b）有新的作弊线索**：如果冰冻切片只出现在「正常 + 少数肿瘤」中，制片方式仍然和标签相关。要让每一类的冰冻 / FFPE 比例相同（例如每类都是 2 冰冻 + 2 FFPE），测试集同理。另外 FFPE 正常肺有没有别的公开来源（GTEx 等）需要在 R1 前查清，不能只写「待查」。
**M4 · ADR-003 的容量估算基于乳腺切片**：肺切除标本通常比这张大，「1–3 个 Worker」没有依据。另外「静态资源请求免费且不限量」这一点 R0 没写出处。修复：M1 先切一张最大的肺切片实测，并附 Cloudflare 官方限额链接。

## Minor

- m1 R0 状态表里 CI 写「已写未跑」：代码已推送、PR 已开，以 PR 上的 CI 结果为准，需要更新。
- m2 R0 中文、ADR 英文，语言不一致；README 对外用英文可以，审核文档建议统一。
- m3 「10×」是屏幕换算倍数（10× 下 1 屏幕像素 ≈ 1 µm），真实 10× 物镜视野直径约 2 mm，界面应标注「等效倍数」，避免新人误以为和显微镜一致。
- m4 跳过的空白瓦片返回 404：确认 OpenSeadragon 不会因此反复重试；如果会，改为在 DZI 旁放一份空白瓦片列表或用一张共享的白色瓦片。
- m5 ADR-004 只防误见：练前 / 练后测的答案也在公开目录里，ADR 应写明这对 n=1 的自测是可接受的风险（结果只代表「诚实作答」）。
- m6 ADR-005 写的「对研究设计没有影响」不完全对：乳腺被排除在「其他部位」之外，可选部位少了一个，应写出来。

## 结论

B1 修好前不建议进入 M1（M1 会按当前 schema 批量生成 28 个病例文件）。M1–M4 修文档和 schema 即可，工作量小，我可以一次改完。
