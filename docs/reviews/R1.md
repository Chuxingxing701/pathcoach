## 3. 已知问题与技术债

- **WSInfer 模型不适用鳞癌**：`lung-tumor-resnet34.tcga-luad` 在 2 张 LUSC 上把 91–95% 组织块判为 Benign（域外失效）；在 LUAD 片上能给出空间连贯的肿瘤热区（~33% patch）。R3 决策：AI 区域圈只对 LUAD 病例启用或干脆不做（详见 `pipeline/wsinfer-report.md`）。
- **GDC 下载不稳定**：other-03 五次断连；下载脚本有断点续传但链路本身慢（~1–2 MB/min）。不影响产物正确性，只影响排期。
- **normal 病例的 `primaryDiagnosis` 语义**：GDC 病例级诊断是「患者的癌诊断」，正常片（Solid Tissue Normal）若照搬会产生矛盾叙述。已改：truth=normal → `primaryDiagnosis: "Normal lung tissue"`（患者癌诊断仍可从 source 推断，但不再显示）。
- **Windows 本地 `npm run check` 曾因 autocrlf 全挂**：已加 `.gitattributes`（`eol=lf`）并归一化工作区；CI（Linux）本就正常。
- **npm audit**：10 个 moderate 漏洞（`npm ci` 时报告），未处理，记入 backlog。
- **answers/*.json 是公开文件**：只能防「意外看到」，防不了有心翻文件作弊——规格中已声明此边界。
